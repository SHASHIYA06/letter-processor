## Purpose

This directory is the engineering source of truth for the BEML Multi-Project Metro
Document Intelligence Platform. Every document describes the **actual implementation**
or is explicitly labelled **Proposed** / **Not implemented**.

## Documentation standards

1. Every document carries Version, Status, Purpose, Scope, and Open Issues.
2. Implemented vs proposed features are always labelled. Never present a proposal as done.
3. No API keys, passwords, passcodes, session tokens, or production secrets appear in any document.
4. Documents are updated in the same change as any architecture, schema, API, or workflow change.
5. Related documents are cross-linked.

## About `node_modules/`

`node_modules/` is **generated by the package manager** (`npm install`) and is
explicitly *not* a documentation deliverable. It is excluded from version control via
`.gitignore`. The dependency list that documents it lives in the repository
`package.json` and in [TRD.md](TRD.md) §Dependencies. Do not create a Markdown file
named `node_modules`.
